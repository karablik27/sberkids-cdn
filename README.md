# Контент приколов на CDN

В этой папке: `vines.json` — лианы, `pet.json` — Жилец, `images/` — картинки.
Для демо адрес папки можно подменить аргументом запуска `-CDNBaseURL https://…/cdn/`.

# Лианы

Приложение при каждом открытии главного экрана скачивает `vines.json` и выбирает один пак.
Релиз не нужен: правите JSON или картинки — изменения видны при следующем открытии.

Порядок выбора источника: CDN → кэш ранее загруженного CDN-конфига. Встроенного конфига лиан в приложении нет.

## Корень конфига

| Поле | Что делает |
|---|---|
| `enabled` | Выключатель всей пасхалки |
| `cooldownMinutes` | Не показывать чаще, чем раз в N минут (0 — при каждом открытии) |
| `forcePack` | id пака, который показать принудительно — для демо и проверки |
| `packs` | Список паков |

## Пак

Все поля, кроме `id`, необязательны.

| Поле | Пример | Что делает |
|---|---|---|
| `id` | `"halloween"` | Имя пака |
| `weight` | `5` | Вес при случайном выборе среди активных паков |
| `from`, `to` | `"12-15"`, `"01-10"` | Сезон (месяц-день), повторяется каждый год, может переходить через Новый год |
| `glyphs` | `["0","1"]` | Символы-звенья |
| `images` | `["images/pumpkin.png"]` | Картинки-звенья (путь относительно конфига или полный URL). Важнее `glyphs` |
| `head` / `headImages` | `["images/spider.png"]` | Что висит на кончике |
| `itemEvery` | `3` | Звено на каждом N-м сегменте, 0 — только нить и кончик |
| `flicker` | `true` | Символы мерцают, как в Матрице |
| `colors`, `headColor` | `["#12B33A"]` | Цвет символов |
| `thread`, `threadWidth` | `"#2E6B3A"`, `2` | Нить между звеньями |
| `glow` | `"#12B33A99"` | Свечение |
| `glyphSize`, `headSize` | `[10,17]`, `26` | Размер звеньев и кончика, pt |
| `count` | `8` | Сколько лиан (верхняя граница) |
| `spacing` | `0.12` | Минимальный интервал между лианами как доля ширины экрана (0.12 = 12%); при большем интервале лиан будет меньше |
| `overlapOpacity` | `0.38` | Непрозрачность лианы поверх отмеченного элемента UI (0 — невидима, 1 — полностью видна) |
| `length` | `[0.1,0.3]` | Длина лианы — доля высоты экрана |
| `sway` | `1.4` | Сила покачивания |
| `tearSpeed` | `900` | Насколько резким должен быть смах, чтобы сорвать (pt/с) |
| `haptic` | `true` | Вибрация при отрыве |
| `sound` | `{"enabled":true,"volume":0.8,"files":["sounds/vines/matrix_1.wav"]}` | Звуки движения; пути считаются от `vines.json` |

## Картинки

PNG @3x, прозрачный фон, точка подвеса — сверху по центру.
Картинки кэшируются навсегда по адресу, поэтому **новую картинку кладите под новым именем**, а не перезаписывайте старую.

## Звуки лиан

Звуки лежат в `sounds/vines/`. Каждый пак задаёт свой набор файлов, громкость и выключатель в `sound`. Если файл временно недоступен, приложение пропустит его; скачанные файлы кэшируются.

# Маскот (`pet.json`)

| Поле | Что делает |
|---|---|
| `enabled` | Выключатель |
| `firstOpenOfDay` | Появляться при первом открытии за день |
| `randomChance` | Шанс (0…1) появиться при любом открытии |
| `onShake`, `onEvents`, `onCharging` | Включены ли тряска, события приложения, зарядка |
| `triggers` | Переопределение триггеров на вьюхах по id: `{"avatar": {"gesture": "doubleTap", "action": "summon", "enabled": true}}`. Жесты: `tap`, `doubleTap`, `tripleTap`, `longPress`. Действия: `summon`, `toggle`, `home`, `celebrate`, `event:topUp`, `say:<ключ реплики>` |
| `stayMinutes` | Через сколько минут без внимания уходит домой |
| `behaviors` | Веса поведения: `walk`, `idle`, `sit`, `wave`, `hop`, `sleep`, `dance` |
| `walkSpeed` | Скорость ходьбы, pt/с |
| `nightSleepBoost` | Во сколько раз чаще спит ночью (22:00–7:00) |
| `reactions` | **Событие → реакция.** Для каждого события: `say` (реплики, случайная), `sayChance` (0…1), `sound` (файлы, случайный), `soundChance`, `volume` (0…1), `animation` (встроенные `celebrate`, `wave`, `dance`, `sit`, `sleep`, `hop`, `jump` или своя из `character.json` персонажа; работает на любом событии, на `tap` — вместо прыжка), `cooldown` (секунд между повторами), `maxPerVisit` (сколько раз за визит). Реплика — строка или объект `{"text", "maxPerVisit", "first", "duration"}`: `first: true` — гарантированная, звучит первой (без учёта `sayChance`), пока не исчерпан её `maxPerVisit`, и её не перебивают другие реплики. Визит — пока маскот на экране; ушёл и позвали снова — лимиты обнуляются. Реплик и звуков в коде нет — только то, что задано здесь. Свои события (например `secret`) можно завести здесь и вызвать триггером `react:secret` |
| `sounds` | Общие настройки звука: `enabled`, `volume` (0…1) |
| `skins` | Костюмы: `id`, `from`/`to` (сезон), `hat` (картинка или `"none"`), `fur`, `face` (цвета) |
| `forceSkin` | Принудительный костюм — для демо |
| `characters` | Персонажи из деталей: `id`, `path` (к `character.json`), `from`/`to` (сезон), `weight` (0 — только принудительно), `scale` (свой размер). Сезонный важнее круглогодичного. Нет подходящего или не загрузился — маскот не появляется |
| `forceCharacter` | Принудительный персонаж — для демо |
| `bubble` | Окно реплики: `fontSize` (9–24), `maxWidth` (100–320 pt), `maxLines` (1–6), `textColor`, `background`, `opacity` (0.2–1, по умолчанию 0.5), `blur` (матовое размытие: скрывает то, что под репликой, и даёт сероватый оттенок; по умолчанию выключено), `cornerRadius`, `duration` (секунд висит обычная реплика; гарантированная — почти вдвое дольше, если у неё не задан свой `duration`) |
| `scale` | Размер маскота относительно нарисованного (по умолчанию 0.75). У персонажа в `characters` может быть свой `scale` |

## События маскота для `reactions`

| Событие | Когда |
|---|---|
| `hello` / `night` / `comeBack` | Пришёл: первый раз за день / ночью / в другой раз |
| `descend` / `fall` / `appear` | Появился: спустился на ниточке / упал сверху при тряске / выпрыгнул из вьюхи |
| `disappear`, `bye` | Ушёл в домик |
| `land`, `hardLanding`, `dizzy` | Приземлился / сильно ударился / кружится голова (повторяется) |
| `tap`, `grab`, `thrown` | Тапнули / схватили / кинули |
| `shake`, `tilt`, `upsideDown` | Тряска / наклон / телефон вверх ногами |
| `hop`, `snore`, `celebrate` | Прыгнул на карточку / посапывает во сне (повторяется) / начал радоваться |
| `topUp`, `taskDone`, `achievement`, `charging` | События приложения и зарядка |
| любое своё | Вызывается триггером на вьюхе: `"action": "react:<имя>"` |

Старые поля `phrases` (только реплики) и списки файлов в `sounds` тоже понимаются, но `reactions` важнее.

# Свой персонаж — `characters/<имя>/`

Персонаж собирается из картинок-деталей по `character.json`. Код приложения менять не нужно: можно сделать зверька, машинку, ракету — что угодно. Примеры: `characters/monkey/` и `characters/car/`.

```json
{
  "size": [80, 50],          // рамка персонажа, pt; (0,0) — левый верхний угол; смотрит вправо
  "foot": [40, 50],          // точка опоры — ей стоит на карточках (по умолчанию низ по центру)
  "head": [46, 6],           // над ней звёздочки, «z» и реплики
  "parts": [                 // по порядку отрисовки: первая — самая дальняя
    { "id": "wheelBack", "image": "wheel.png", "size": [18, 18], "at": [20, 41],
      "motion": { "walk": { "spin": 45 } } },
    { "id": "eyes", "images": { "normal": "eyes_normal.png", "happy": "eyes_happy.png", "blink": "eyes_blink.png" },
      "size": [20, 10], "at": [46, 16] }
  ]
}
```

**Деталь:**

| Поле | Что задаёт |
|---|---|
| `image` / `images` | Картинка или картинки по эмоциям: `normal`, `blink`, `happy`, `sleepy`, `dizzy`, `scared` |
| `size` | Размер детали, pt |
| `at` | Куда в рамке ставится точка вращения детали |
| `pivot` | Точка вращения внутри детали, доли 0…1 (плечо — `[0.5, 0]`, по умолчанию центр) |
| `fit` | Вписать картинку с сохранением пропорций (для шапки из костюма) |
| `motion` | Движения по состояниям |

Деталь `hat` подменяется шапкой из сезонного костюма (`skins`). Если у неё нет своей картинки, она появляется только с костюмом.

**Состояния:** `walk`, `idle`, `sit`, `sleep`, `wave`, `dance`, `celebrate`, `grabbed`, `air`, `dizzy`, `descend`, `default` (для всех остальных).

**Свои анимации** — раздел `animations` в `character.json`. Движения деталей задаются в `motion` под тем же именем:

```json
"animations": {
  "party": { "duration": 2.6, "spin": 280, "bob": 6, "freq": 2.5, "expression": "happy", "effect": "sparkles" }
},
"parts": [ { "id": "armLeft", "motion": { "party": { "rotate": 160, "swing": 30 } } } ]
```

| Поле | Что задаёт |
|---|---|
| `duration` | Длительность, секунды (до 15) |
| `spin` | Вращение всего персонажа, градусов в секунду |
| `bob`, `sway`, `freq` | Подпрыгивания и покачивание всего персонажа (pt) и сколько раз в секунду |
| `expression` | Эмоция: `normal`, `happy`, `sleepy`, `dizzy`, `scared` |
| `effect` | Эффект вокруг: `sparkles`, `stars`, `zzz` |

Вызвать анимацию можно на **любое событие** — `"animation": "party"` в `reactions` (тап, приземление, бросок, тряска, наклон, события приложения, секретные триггеры) — или сделать её поведением: `"behaviors": { "party": 0.3 }`. Если на `tap` задана анимация, персонаж делает её вместо прыжка. Если у текущего персонажа такой анимации нет, она просто не играет.

**Движение** (всё необязательно):

| Поле | Что задаёт |
|---|---|
| `rotate`, `dx`, `dy`, `scale` | Постоянный поворот (градусы), сдвиг (pt), масштаб |
| `swing`, `bob`, `sway` | Размах колебаний: поворотом, вверх-вниз, влево-вправо |
| `freq`, `phase` | Частота колебаний и сдвиг фазы (0.5 — в противофазе, как у второй ноги) |
| `spin` | Постоянное вращение — для колёс |
| `hidden`, `image` | Спрятать деталь или подменить картинку в этом состоянии |

В движении (`walk`, `air`, `dance`…) колебания идут в такт шагам, в покое — по времени.

Картинки: PNG @3x с прозрачным фоном. Персонаж целиком обычно весит 50–100 КБ.

# Как проверить свой контент

Приложение после загрузки проверяет конфиг и персонажа и пишет подсказки в системный журнал: в Xcode — консоль, на Mac — приложение «Консоль» (можно с подключённого телефона), фильтр `MascotKit`. Там будет, например: «Реакция «tap» ссылается на анимацию «paty», а её нет ни среди встроенных, ни у персонажа «snowman» — анимация не сыграет». Опечатка не ломает маскота — он просто не сделает то, что описано с ошибкой.
